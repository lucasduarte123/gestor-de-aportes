# 📊 Gestor de Aportes Inteligente

Aplicação interativa para controle de carteira de investimentos, análise de alocação e cálculo de aportes inteligentes.

## 🛠️ Tecnologias
- Python 3.x
- Streamlit
- Pandas & NumPy

## 🚀 Como Executar
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute a aplicação: `streamlit run app.py`
